Voice + agent tools over Pepebot's /v1/live proxy — session web-session

Disconnected

This page declares tools of its own — device_info and geolocate — which Pepebot registers as web-* and routes back here to run in the browser. Ask "what timezone am I in?" and the browser answers, not the gateway. Models and voices come from Paniki's /v1/models and /v1/voices, so nothing here goes stale on a redeploy. Paniki fixes modalities and the audio formats server-side, so this page never sends them — and it leaves instructions alone, because Pepebot has already put the agent persona, its skills and its tools there.
